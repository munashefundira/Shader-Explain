“ShaderExplain”: Tool-Augmented LLM System for Explaining Computer Graphics Shader Programs

Motivation / Value:
Shader programs (vertex and fragment shaders) are a core part of modern Computer Graphics but are difficult for students to understand due to their mathematical nature and parallel execution model. Instructors spend significant time explaining simple shaders repeatedly. An automated explanation tool can help students grasp shader logic and rendering effects more effectively.

Research Grounding:
Builds on research in LLM-based code understanding and domain-specific program explanation, extending these ideas to graphics shader languages (GLSL). Related work appears in recent studies on LLMs for program comprehension and STEM education (arXiv).

Project Idea:
Develop a tool-invoking LLM system that explains simple vertex and fragment shaders using structured analysis instead of free-form reasoning.
The system invokes tools to extract:
Shader type (vertex / fragment)
Input and output variables
Transformation and lighting computations
Color and texture operations
Using these tool outputs, the LLM generates a clear, step-by-step explanation of how the shader processes data and affects the final rendered image.

Deliverable:
A CLI or web-based application that accepts a GLSL shader file and produces:
Line-by-line explanation
Summary of rendering effect (e.g., flat color, lighting, texture mapping)
Key mathematical operations involved

Evaluation / Research Component:
Evaluate explanation accuracy and student understanding through short quizzes. Compare the results with explanations generated by a plain LLM without tool invocation to demonstrate improved reliability and clarity.
